### 📅 [Exam Scheduler](https://github.com/AungKoKoLatt18/Exam-Scheduler)
> Python tool that automatically schedules exams and assigns research assistants (RAs), working from an Excel sheet.
> `Python` · `Excel`

### 📡 [Data Transmission Error Detection](https://github.com/AungKoKoLatt18/Data-transmission-error-detection)
> Socket-based simulation of a noisy network: a sender attaches a check code, a server damages the message, and a receiver detects (or corrects) the error. Implements **Parity, 2D Parity, CRC16, Hamming and Checksum**.
> `Python` · `Sockets` · `Networking`

### 🌤️ [Weather App](https://github.com/AungKoKoLatt18/weather-app)
